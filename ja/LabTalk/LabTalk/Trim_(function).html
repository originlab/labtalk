概要

この関数は文字列から空白を削除します。パラメータnを持ち、文字列の先頭と末尾のスペースを削除するか、文字列内のスペースを含むすべてのスペースを削除するかを選択できます。

構文

string Trim(string str$[, int n = 0])$

パラメータ

str

スペースを削除する文字列。

n

削除するスペースの種類を指定します。次のオプションがあります。
0 （デフォルト） 先頭、末尾、単語間のスペースを含む余分なスペースを削除します。単語間のスペースは1つだけ保持されます。
1 文字列内のスペースも含めて、すべてのスペースを削除します。


戻り値

スペースが削除された文字列を返します。

サンプル

string str1$ = " abc ABC "; 
string newStr1$ =Trim(str1$,0)$ ;
newStr1$ = ; //結果は "abc ABC"となる
string str2$ = " abc abc ";
string newStr2$ = Trim(str2$,1)$;
newStr2$ = ; //結果は "abcabc"となる
Trim("1.Olivia              Grace         Bennett")$=; // "1.Olivia Grace Bennett"を返す
