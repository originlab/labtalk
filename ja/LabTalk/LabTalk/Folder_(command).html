構文

folder [option] argument

オプション：

-dup; 現在のフォルダを複製する

構文： folder -dup FolderName

  • 次のようにFolderNameが省略された場合、
folder -dup;

現在のフォルダを複製し、デフォルト名（例：Folder#）で新しいフォルダを作成します。

  • 複数の複製フォルダを作成する場合は、複数のフォルダ名を「|」で区切って指定します。現在のフォルダは、指定した名前ごとに1回複製されます。例えば、
folder -dup Boston|New York|Washington DC;

「Boston」、「New York」、および「Washington DC」という名前の現在のフォルダのコピーを3つ作成します。

  • 「?」がFolderNameとして指定された場合は、
folder -dup ?;

フォルダを複製ダイアログを開きます。

サンプル：

EX1

実験データが日ごとのフォルダに格納されているとします（フォルダ名はACCESS-CM1, ACCESS-CM2, ACCESS-CM3のような形式です）。データコネクタで、共通データパスをプロジェクトパスからの相対パスに設定し、プロジェクトエクスプローラフォルダをサブフォルダ名として使用を有効にします。ACCESS-CM1の解析とグラフ化が完了したら、-dupを使用して他の日の対応するフォルダを作成します。 

for(int ii=2;ii<10;ii++)
{
string strFolder$ = "ACCESS-CM"+"$(ii)";
folder -dup %(strFolder$);
}
