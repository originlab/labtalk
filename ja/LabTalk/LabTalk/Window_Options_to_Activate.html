アクティブ化/非表示/最大化/最小化のオプション

Window_Options_to_Activate


-a

構文： window -a winName

winNameをアクティブウィンドウとして設定します。
このオプションは、アクティブなウィンドウが最大化または最小化されている場合、ウィンドウの復元と同じ効果があります。 

repeat 5 {newbook;}; // 新規のワークブックを5つ作成
window -a book3; // Book3ウィンドウをアクティブ化

この例では、2つのグラフが水平に並べて表示され、他のウィンドウはすべてアイコン表示されます。 

newbook;wks.nCols=3; //3列をもつ新規のワークブック
col(1)=data(1,10);
col(2)=normal(10);
col(3)=col(1)+col(2);// データを入力

range aa = (1,2);    // XY範囲を定義
range bb = (1,3);
string strG1$, strG2$; // 新しいプロット名を受け取るためのローカル文字列

plotxy aa ogl:=[<new>];strG1$=%H;
plotxy bb ogl:=[<new>];strG2$=%H;

doc -e o {win -i}; // すべてのウィンドウをアイコン化
win -a %(strG1$);  // 2つのグラフを開く
win -a %(strG2$);

win -s tv;         //水平に並べる

-af

構文： window -af [n] [millisecond]

millisecondのタイムアウトでn回アクティブウィンドウをフ点滅させます。

  • nもmillisecondも指定されていない場合、アクティブウィンドウはデフォルトで4回点滅し、タイムアウトはシステム変数@AWFで設定されます。@AWF=0の場合は点滅しません。
  • nが指定、millisecondが未指定の場合、デフォルトで200msタイムアウトを使用します。
  • nが負の整数で、millisecondが指定されていない場合、タイムアウトはシステム変数@AWFの設定によります。@AWF=0の場合は点滅しません。
win -af;//4回点滅、@AWFで設定されたタイムアウトを使用、@AWF = 0の場合は点滅なし
win -af 5;//5回点滅、200msタイムアウトを使用
win -af 5 300;//5回点滅、300msタイムアウトを使用
win -af -5;//5回点滅、@AWFで設定されたタイムアウトを使用、@AWF = 0の場合は点滅なし

-an; winNameという名前のノートウィンドウをアクティブ化

構文： window -an winName

winNameという名前のノートウィンドウをアクティブ化または復元します。 

//埋め込みノートウィンドウをポップアップさせる
win -an %@G;

-b

構文： window -b winName

指定したウィンドウを開くか、アクティブに設定します。
このコマンドオプションは廃止されました。 代わりにGetNamedWinマクロを使用します。
例:
この例では、ウィンドウメニューのウィンドウリスト内のgraphで始まる最初のウィンドウを検索し、アクティブウィンドウとして設定します。 ウィンドウが見つからない場合は、Graph1ウィンドウを作成します。 

win -b graph;

-ch

構文： window -ch n

アクティブなウィンドウを非表示にします（ウィンドウのプロジェクトエクスプローラ表示モードが変更されます）。

  • n=1、アクティブなウィンドウを非表示にする
  • n = 0、アクティブなウィンドウを表示する

例えば、ウィンドウが標準ビューであった場合、n=1のときに非表示ビュー(プロジェクトエクスプローラ表示列)に変わります。 win -hも参照してください。 

newbook name:=Test option:=lsname; // "Test"という名前の新規ワークブックを作成すると、
                                   //作成と同時に自動的にアクティブになる
window -ch 1; // ワークブックTestを非表示
window -a Test; // 表示を復元

-h

構文： window win -h n

アクティブなウィンドウを非表示にします（ウィンドウのプロジェクトエクスプローラの表示モードは変更されません）。

  • n=1、アクティブなウィンドウを非表示にする
  • n = 0、アクティブなウィンドウを表示する

ウィンドウのプロジェクトエクスプローラの表示モードは現在のビュー（標準、最大化など）に設定されたままですが、表示されません。 win -chも参照してください。

-hc

構文： window win -hc n [windowName]

アクティブなウィンドウまたは名前付きウィンドウを非表示にし、表示モードを変更します。これはwin-chと同じですが、windowNameオプションをサポートしています。 

// Book2を非表示（このワークブックがアクティブウィンドウでない場合にも適用）
win -hc 1 Book2;

// 'win -ch 1'は次のように機能する
win -hc 1;

-hn

構文： window win -hn n NotesWindowName

ノートウィンドウを表示または非表示にします。

  • n = 1; ノートウィンドウを非表示
  • n = 0; 非表示のノートウィンドウを表示

-i

構文： window -i

アクティブなウィンドウを最小化します。

-ia

構文： window -ia

アクティブウィンドウを最小化し、以前アクティブにしたウィンドウを強制的にアクティブ化します。

-in

構文： window -in winName

winNameという名前のノートウィンドウを最小化します。

-r

構文： window -r

現在のウィンドウを最大化または最小化から復元します。

構文： window -r windowName newName

指定したnewNameで windowName の名前を変更します。

-z

構文： window -z

アクティブなウィンドウを最大化します。

-zn

構文： window -zn winName

winNameという名前のノートウィンドウを最大化します。
