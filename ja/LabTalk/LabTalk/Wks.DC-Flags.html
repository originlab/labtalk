構文

wks.DC.Flags

アクセス

読み/書き
数値

概要

インポートしたファイルのデータ行をアクティブなワークシートに追加します。Origin 2021の時点で、Data Connector = Text/CSVのみです：

0=（デフォルト）追加しない
128=インポート時に列ごとにデータを現在のシートに追加
256=インポート時に行ごとにデータを現在のシートに追加

サンプル

string next, fname, path$=system.path.program$ + "Samples\Batch Processing\"; 
findfiles fname:=fname$ ext:="*.csv";
wbook.dc.add("CSV");
wks.dc.flags=128;	// 列追加モードをオンに
int num = fname.GetNumTokens(CRLF);
loop(ii,1,num)
{
	next$ = fname.GetToken(ii, CRLF)$;
	wks.dc.source$=next$;
	wks.dc.import();
}
