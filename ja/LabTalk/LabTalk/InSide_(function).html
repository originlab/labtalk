概要

この関数は、マッチするマークのペアを使用して部分文字列を抽出します。

構文

string InSide(string str$[, int nQuote])$

パラメータ

str

文字が抽出される文字列。

nQuote

引用符、デフォルトでは二重引用符（""）を使用。1 = ( ), 2 = [ ], 3 = < > , 4 = { } , 5 =一重引用符

戻り値

マッチするマークのペアで囲まれた部分文字列を返します。。

サンプル

EX1 

inside("(1) Which do you like?(apple,  banana)", 1)$=; //1
