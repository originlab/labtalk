メニュー

Menu-cmd

メニュー、サブメニュー、メニューコマンドの追加、削除、編集 メニュー操作の詳細については、menuオブジェクトを参照ください。

Note: XMLファイルを編集してメニュー操作を行うこともできます。

構文

menu  [option] <argumentList [{script}]>

menu コマンドの効果はすぐには現れない場合があります。別の種類のウィンドウをアクティブにしてから、元のウィンドウに戻って結果を確認してください。


アクティブなメニューバーを選択

メニューは、子ウィンドウのタイプ（ワークブック、グラフ、行列、レイアウト）ごとに異なります。 アクティブなメニューバーを選択するには、-g (グラフ)、-w (ワークブック)、-p (レイアウト)、または-m (行列)コマンドオプションを使用します(下記のオプションを参照してください)。

注意：ウィンドウの指定を組み合わせることができるます。例えば　menu -gp;　とすると、

これ以降のメニュー変更をグラフウィンドウとレイアウトページウィンドウの両方に適用します。

アクティブなメニューを選択

全てのコマンドはアクティブウィンドウに対して操作を実行します。アクティブなメニューを選択するには、次のいずれかを実行します。

  • メニューバーで現在の位置を参照（「オプションが指定されていない場合」セクションを参照）。
  • タグを使用。 例：
menu ?Ed; //編集メニューをアクティブにする

この方法で参照できるのは組み込みメニューのみです（ユーザ定義メニューの場合は位置を参照）。タグは2文字である必要があります。 以下のタグが使用されます。

メニュー タグ 適用可能なウィンドウ
ファイル Fi w, g, m, p
編集 Ed w, g, m, p
表示 Vi w, g, m, p
作図 Pl w, m
グラフ操作 Gr g
データ Da w, g
解析 An w, g, m, p
フォーマット Fo w, g, m, p
レイアウト La p
行列 Ma m
イメージ Im w, m
ウィンドウ Wi w, g, m, p
統計 St w
ツール To w, g, m
列 Co w
ヘルプ He w, g, m, p


メニューコマンドIDを検索する

メニューコマンドIDを検索するには、次のいずれかを実行します。

  • Ctrl+Shiftキーを押して、任意のメニューオプションを選択します。 メニューID（および該当する場合はスクリプト）がスクリプトウィンドウに入力されますが、実行されません。メニューオプション(LabTalkまたはOrigin C)のソースコードが存在する場合、コードビルダーはソースファイルとともに開きます。
  • menu.lastIDまたはmenu.lastExeIDオブジェクトプロパティを使用します。

オプション：

オプションなし

構文： menu message

オプションが指定されていない場合（つまり、-dなどのダッシュオプションが指定されていない場合）、メニューコマンドには4つのアクションがあります。

argumentList が数値のみで構成されている場合：

番号の付いた位置のメニューがアクティブなメニューとして設定されます。メニューを編集するには、メニューをアクティブに設定する必要があります。メニューには順番に番号が付けられており、1=ファイル、2=編集などです。サブメニューを選択することもでき、1.1はファイルメニューの最初のmenu コマンドのサブメニューになります。サンプル1： 

menu 2;

アクティブなメニューバーの位置番号2のメニューをアクティブに設定します。サンプル2： 

menu 1.1;

アクティブなメニューバー内のメニュー1において、位置1にあるサブメニューをアクティブに設定します。

argumentList が「数値」の後に「名前」が続く形である場合：

名前付きメニューが作成され、アクティブなメニューバーの指定された位置に挿入され、トップレベルメニューが作成され、アクティブなメニューとして設定されます。例： 

menu 2 (My Menu);

アクティブなメニューバーの位置2にMy Menuを挿入します。 "( )" はMy Menuを単一の単語として扱うために用います。

argumentList が数字で始まらない場合:

アクティブなメニューバーのアクティブなメニューに追加される新しいメニューコマンドの名前と見なされます。新しいメニューコマンドはスクリプトscriptを実行します。例： 

menu (Add Text) {label -e NewText;}

アクティブなウィンドウに新しいテキストラベルを追加します。

argumentListが与えられていない場合:

アクティブなメニューバー内のアクティブなメニューにメニューコマンド区切り文字が追加されます。例： 

menu 6;
menu;

メニューコマンド区切り文字をメニュー6に追加します。

この例では、位置5（グラフメニューとデータメニューオプションの間）に、2つのメニューオプションとセパレータを持つ新しいグラフメニューを作成します。 

menu -g;
menu 5 (Publish);
menu (To Journal) {type -a Add code here;}
menu;
menu (To Web) {type -a Add code here;}

-cr; 全ての折りたたみを初期状態のデフォルトにリセット

構文： menu -cr

必要なOriginのバージョン: Origin 2015 SR0以降

これにより、メインメニューとコンテキストメニューの両方で、折り畳み可能なOriginメニューが工場出荷時のデフォルトにリセットされます。

-d; アクティブメニューのposition位置にあるメニューコマンドを削除

構文： menu -d position

アクティブなメニュー(アクティブなメニューバー内)のposition位置にあるメニューコマンドを削除します。セパレータが目標位置になることがあります。削除されたメニューの下のメニューが上に移動するため、繰り返しでは複数のメニューが削除されます。 

menu -w;               // ワークブックメニューがアクティブ
menu ?Co;              // 列メニューがアクティブ
// メニュー内の最後の7項目を削除、1つのセパレータを含む
repeat 7 {menu -d 17;}

menu.cleanup()はすべてのメニューを復元します。LabTalk:言語リファレンス:オブジェクトのアルファベット順のリスト:メニューオブジェクトを参照してください。

-e; 指定したIDでメニューコマンドを実行

構文： menu -e ID

指定されたIDを持つメニューコマンドを、そのスクリプトを即座に実行することで呼び出します。上記のメニューコマンドIDを検索するを参照してください。

注意:特定の状況下では"menu -e"が動作しない場合があります。その際は代わりに"menu -eo"を試してください。

-g; グラフウィンドウのメニューバーを選択してメニュー操作を行う

構文： menu -g

グラフウィンドウのメニューバーを選択してメニュー操作を行います。

-i; アクティブなメニューバーのmenuNameという新しいメニューコマンドをposition位置に挿入

構文： menu -i position menuName {script}

アクティブなメニューバーのアクティブなメニューの位置に、menuNameという名前の新しいメニューコマンドを挿入します。MenuNameはスクリプトscriptに関連付けられています。このメニューを追加するときは、menu -w;のように、1つのメニューバーだけをアクティブにする必要があります。menu -wg;のように複数のメニューバーがアクティブな場合、メニューは追加されますが、スクリプトは実行されません。

-i; position位置のアクティブなメニューバーのmunu ID IDを持つ新しいメニューコマンドmenuNameを挿入

構文： menu -i position menuName ID

アクティブなメニューのposition位置に、menuNameという名前でメニューIDがIDの新しいメニューコマンドを挿入します。このコマンドオプションは、ツールにリンクする特定のIDを持つメニューコマンドを作成するために使用されます。

-l; アクティブなメニューの最後にサブメニューを作成

構文： menu -l [-i position] (menuName) {script} ]

アクティブなメニューの最後にサブメニューを作成します。menu -lコマンドは2回発行される必要があります。最初にサブメニューに名前を付けて初期化し、2回目に説明したサブメニューを構築します。 プロトコルは次の通りです。 

menu -l (New Submenu);  
  // サブメニュー開始
menu (submenu 1) {type "this is submenu 1"};
menu (submenu 2) {type "sub menu 2"};
menu -l;  
  // サブメニュー終了

このスクリプトは、New Submenuという名前のサブメニューを作成します。 このサブメニューには、2つのメニューコマンドが含まれています。-lとmenuNameの間に -i positionオプションが追加されていれば、アクティブなメニューの特定の位置にサブメニューを構築することもできます。

注意:ウィンドウメニューにメニュー項目を追加する場合は、ウィンドウのサブメニューリストの前に(menu -i posを使用して)新しい項目を挿入する必要があります。Originは位置16の下にサブメニューを作成しようとし、位置16にメニューを作成します。

-m; メニュー操作のため行列ウィンドウメニューバーを選択

構文： menu -m

メニュー操作のため行列ウィンドウメニューバーを選択します。

-p; メニュー操作のためレイアウトページウィンドウのメニューバーを選択

構文： menu -p

メニュー操作のためレイアウトページウィンドウのメニューバーを選択します。

-q; そのスクリプトをキューイングして、指定したIDでメニューコマンドを実行

構文： menu -q ID

指定したIDでメニューコマンドを実行するには、そのスクリプトをキューに入れて実行します。上記のメニューコマンドIDを検索するを参照してください。

-r; position位置にあるメニュー全体を削除

構文： menu -r position

position位置にあるメニュー全体を削除します。これはトップレベルのメニューを削除し、3.6のようなサブメニュー表記では使用できません。次のようにタグを参照することもできます。 

menu -r ?He;   // アクティブなメニューバーからヘルプメニューを削除

-sns; 付箋カラーリストを保存

構文： menu -sns

付箋カラーリストをユーザファイルフォルダ内のOrigin.iniに保存します。

-w; メニュー操作用のワークシートメニューバーを選択

構文： menu -w

メニュー操作のワークシートメニューバーを選択します。


-v; アクティブなウィンドウがない場合のメニュー操作用のメインメニューバーを選択

構文： menu -v

アクティブなウィンドウがない場合は、メインメニューバーを選択してメニュー操作を行います。

サンプル：

サンプル1:メニューとサブメニューの追加(-lオプションなし)

次のスクリプトは、アクティブなメニューバーの3番目の位置にNewDDメニューを挿入してアクティブにします。 （アクティブなメニューが設定されていない場合、このコマンドは無効です。） 

menu 3 (NewDD);

次のスクリプトは、アクティブなメニューバーの[編集]メニューの前に[Before Edit]メニューを挿入してアクティブにします。 

menu ?Ed (Before Edit);

次のスクリプトは、2番目のトップレベルメニューの4番目の位置にサブメニュー'Sample submenu'を挿入し、アクティブなメニューバーにします。 

menu 2.4 (Sample SubMenu);

サンプル2:メニューとサブメニューの追加(-lオプションを使用)

次のスクリプトは、[編集]メニューの前に[Before Edit]メニューを挿入します。 次に、2つのメニューオプションを追加し、それぞれに2つのサブメニューコマンドがあります。これらのオプションは、ワークブックウィンドウとグラフウィンドウで使用できます。 

menu -wg;
menu ?Ed (Before Edit);
menu -l (Sample Option A);
menu (First Command) {type -b First;}
menu (Second Command) {type -b Second;}
menu -l;
menu -l (Sample Option B);
menu (1st Command) {type -a Option B, first command;};
menu (2nd Command) {type -a Option B, second command;};
menu -l;

サンプル3: メニューの削除

次のスクリプトは、アクティブなメニューバーから4番目のメニューを削除します。 

menu -r 4;

次のスクリプトは、アクティブなメニューバーから[フォーマット]メニューを削除します。 

menu -r ?Fo;

サンプル4:メニューとサブメニューをアクティブにする

次のスクリプトはグラフウィンドウのメニューバーをアクティブに設定します。次に、左から4番目のメニューをアクティブにします。 

menu -g;
menu 4;

次のスクリプトは、アクティブなメニューバーの[表示]メニューをアクティブにします。 

menu ?Vi;

サンプル5: メニューコマンドの削除

Menuコマンドは、アクティブなメニューにのみ追加できます。 したがって、メニューコマンドを追加する前に、目的のメニューをアクティブにします。

次のスクリプトは、[ワークブック]、[グラフ]、[行列]、[レイアウト]メニューバーの[編集]メニューに[EndEdit]というラベルのメニューコマンドを追加します。 

// ワークブック、グラフ、行列 
//およびレイアウトページをアクティブなメニューバーとして使用
menu -wgmp;   
menu ?Ed;     // 編集メニューをアクティブに
menu (EndEdit) {type -b "EndEdit";};

次のスクリプトは、アクティブなメニューバーのアクティブなメニューの5番目の位置にMyItemメニューコマンドを挿入します。 

menu -i 5 (MyItem) {type -b "My item text.";};

次のスクリプトはグラフメニューバーのグラフメニューの2番目の位置にOpen Templateメニューコマンドを挿入します。 

menu -g;  
menu 4;  
menu -i 2 (Open Template) {win -t plot line;};

メニューIDを取得するには、メニューバーから選択して新しいメニューコマンドを実行する必要があります。スクリプトウィンドウに次のように入力し、Enterボタンを押します。 

MyID = i

メニューコマンドは、次のコマンドを使用して後で実行できます。 

menu -e myId;

サンプル6: Menu コマンドの削除

次のスクリプトはグラフウィンドウのメニューバーをアクティブに設定します。 次に、グラフウィンドウのメニューバーの左側から6番目のメニューをアクティブに設定し、このメニューの2番目のメニューコマンドを削除します。 

menu -g;
menu 6;
menu -d 2;

サンプル7: メニューコマンドのセパレータを追加

次のスクリプトは、ワークブックの[解析]メニューの最後にメニュー区切り文字を追加します。そして、メニューに新しいコマンドが追加されます。 

menu -w;
menu ?An;
menu;
menu (My Analysis) {type -b That was easy.;};
