概要

この関数は文字列str$を受け取り、先頭のリストマーカー（数字、文字、または箇条書き記号）とそれに続く空白文字を削除します。リストマーカーは、数値または1文字で始まり、その後に以下のいずれかの区切り文字が続く場合に認識されます：スペース, )（右括弧）、.（ドット）、:（コロン）。詳細についてはEx2を参照してください。

構文

string StripLeading(string str$)$

パラメータ

str

先頭のリストマーカーをトリミングする文字列。

戻り値

str$内の先頭のリストマーカーと後続の空白を削除します。

サンプル

Ex1 

StripLeading("1. this is a test")$=; // "this is a test"を返す
