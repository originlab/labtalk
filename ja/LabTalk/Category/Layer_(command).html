はじめに

既存のレイヤに対してさまざまな操作を実行します。layerコマンドは、指定された場合を除いて、アクティブなレイヤに対して動作します。

これらの機能の多くはlaymanage Xファンクションで使用できます。

構文

layer [option] <width height xOffset yOffset>

オプション：

グラフのオプション

オプション 説明
オプションなし レイヤの位置を設定
-a アクティブレイヤのX軸とY軸を再スケールして、そのレイヤにプロットされたすべてのデータを表示する
-a ma リンクされているすべてのレイヤのX軸とY軸を再スケールして、すべてのデータを表示する
-at 軸目盛設定を無視して、アクティブレイヤのX軸とY軸を再スケールする
-b 3DB グラフ表示キャッシュの設定
-cm l 保存したカラーマップをロードする
-cm s カラーマップを保存する
-gru レイヤ内の既存のグラフオブジェクトの名前を一意にする
-k 作図の詳細（プロット属性）または作図の詳細（レイヤ属性）ダイアログボックスを開く
-n アクティブなグラフウィンドウに新規レイヤ（リンク無し）を追加
-n Both アクティブなグラフウィンドウにリンクレイヤを追加して上X軸と右Y軸を表示する
-n X アクティブなグラフウィンドウにリンクレイヤを追加して上X軸を表示する
-n Y アクティブなグラフウィンドウにリンクレイヤを追加して右Y軸を表示する
-p アクティブなレイヤのXまたはYスケールをアクティブなウィンドウ内の他のすべてのレイヤー適用する
-u レイヤのサイズと位置の単位を変更する
-x レイヤ枠の寸法を変数に保存する

特殊グラフのオプション

オプション 説明
-3d 3Dプロットの視点を制御する
-3d r 3Dグラフの回転を設定する
-3d c GDIベースの3DグラフをOpenGLベースに変換する
-cam 3D OpenGLプロットの方向を制御する
-pgm 2D直交座標レイヤの任意の回転とせん断を有効にする
-Y ? アクティブなグラフウィンドウ内のウォーターフォールグラフを参照し、XオフセットとYオフセットの値を変数XとYに割り当てる
-Y ! アクティブなグラフウィンドウないのウォーターフォールグラフのXオフセットとYオフセットを無効にする
-Y レイヤにプロットされた全データに対してウォーターフォール効果を設定するために、XおよびYオフセットを設定する
-z 極座標プロットの角度と方向をゼロに設定

プロットのオプション

オプション 説明
-b 特別なプロットパラメータ
-c アクティブレイヤにプロットされたデータセットをカウントする
-cx Xデータを変更
-cxy XYデータを変更
-cy Yデータを変更
-e アクティブレイヤからデータセットを削除するが、データプロットスタイルホルダは保持する
-g アクティブレイヤのデータセットをグループ化する
-gu アクティブレイヤのすべてのデータセットのグループを解除する
-hp データプロットの表示/非表示
-i アクティブなグラフウィンドウレイヤ内のすべてのデータプロットスタイルホルダを削除する
-i dataset アクティブなレイヤにデータセットを追加する
-i # #で指定されたプロットタイプに再プロットする
-ic 指定したレイヤからアクティブなグラフレイヤにすべてのデータプロットをコピーする
-ie アクティブなグラフウィンドウレイヤで使用されていないデータプロットスタイルホルダをすべて削除する
-il 既存のラベルなしデータプロットにラベルを追加する
-ip アクティブレイヤにデータセットが存在する場合でも、アクティブレイヤにデータセットを追加する
-iu すべてのデータプロットスタイルホルダーを削除
-j 複数のデータプロットを抽出
-pd # アクティブなプロットを#コピー分複製する
-r アクティブレイヤ内のデータプロットの順番を逆にする
-t nrow データプロットの軸タイトルと凡例テキストを含むワークシート行を設定する

ワークシートのオプション

オプション 説明
-b R ワークシートを編集可能または読み取り専用として設定
-les 保護されたワークシートに編集可能なセルを設定する
-lt 現在の保護ビットを印刷
-lw ワークシートレベルで保護をオンにする
-s Excelワークブックでシートアクティビティを変更したときにOriginを更新する
-se 名前付きExcelシートをアクティブレイヤとして設定
-trv ワークシートの列を列リストビューに切り替える
-us アクティブなExcelシートを更新してデータをコピー
-usn アクティブなExcelシートを更新する（データはコピーしない）
-w 先頭と末尾の列番号と行番号を指定する

レイヤのオプション

オプション 説明
-d アクティブレイヤを削除する
-dk アクティブなレイヤを削除し、ブックを保持する
-f シートを複製
-h レイヤを表示/非表示
-m アクティブなレイヤの「切り取るレイヤの領域」ダイアログボックスを開く
-o 指定したレイヤに対して指定したscriptで操作をを実行する
-s アクティブなウィンドウでアクティブなレイヤを選択する
-tm 結合されたセル範囲を返す
