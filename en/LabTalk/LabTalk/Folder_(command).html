3.3.2.21 Folder

Folder-cmd

Syntax:

folder [option] argument

Options:

-dup; Duplicate the current folder

Syntax: folder -dup FolderName

  • If FolderName is omitted, i.e.,
folder -dup;

duplicates the current folder, creating a new folder with default name (e.g., Folder#).

  • To create multiple duplicate folder, specify mulitple folder names separated by the "|" character. The current folder will be duplicated once for each specified name. For examle,
folder -dup Boston|New York|Washington DC;

creates three copies of the current folder, named "Boston", "New York", and "Washington DC".

  • If "?" is specified as FolderName, i.e.,
folder -dup ?;

opens the Duplicate Folder dialog.

Examples:

EX1

Suppose your experimental data are stored in separate folders for each day, e.g., ACCESS-CM1, ACCESS-CM2, ACCESS-CM3, etc. In the Data Connector, set Common Data Path to Relative to Project Path, and enable Use PE folder as subfolder name. After you complete your analysis and graphing for ACCESS-CM1, use -dup to create corresponding folders for the other days. 

for(int ii=2;ii<10;ii++)
{
string strFolder$ = "ACCESS-CM"+"$(ii)";
folder -dup %(strFolder$);
}
