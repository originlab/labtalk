3.5.3.1.29 Sevcdf

sevcdf-func

Description:

cumulative distribution function for Smallest Extreme Value

Syntax:

double sevcdf(double x, double mu, double sigma[, int iTail])

Parameters:

x (input, double)
The value of the x variate.
mu (input, double)
The location parameter of the distribution.
sigma (input, double)
The scale parameter of the distribution (must be positive).
iTail (input, int)
Tail type, 0 = both, 1 = upper, 2 = lower(default)
