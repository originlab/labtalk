Description

This function extracts a substring using a matching pair of marks.

Syntax

string InSide(string str$[, int nQuote])$

Parameter

str

Is a string or characters from which characters will be extracted.

nQuote

Quote mark, default use double quotation marks (" "). 1 = ( ), 2 = [ ], 3 = < > , 4 = { } and 5 = single quotes

Return

Returns the substring enclosed by a matching pair of marks.

Example

EX1 

inside("(1) Which do you like?(apple,  banana)", 1)$=; //1
