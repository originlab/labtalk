Description

This function takes a vector and transforms it into approximately normal distributed one by using Johnson transformation method.

The three Johnson families of distribution include SB, SL and SU, which are the Johnson families distributions with the variable bounded (SB), lognormal (SL) and unbounded (SU) respectively. And the formulas for the transformation of these three families are:

The function will transform the input dataset by selecting the best transformation function from the three Johnson families.

See detaied algorithm on this page.

Syntax

vector jtrans(vector vd)

Parameter

vd

The input vector (column) to be transformed. vd can include positive, negative and zero numbers.

Return

Transformed vector (column) tby the best transformation function from the three Johnson families mentioned in the Description.

newbook;
col(A) = data(0.1, 1.1, 0.002);
col(B) = jtrans(col(A));
