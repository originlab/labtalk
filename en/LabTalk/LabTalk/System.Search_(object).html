3.7.5.93 System.Search

System-Search-obj

LabTalk Object Type:

Utility

The search object(2026) is a sub-object of the system object. The search object properties allow you to read and alter Plot Details' search box-related settings stored in SYSTEM.CNF file.


Properties:

Property Access Description
system.search.dlg Read/write,
numeric 		search box position, 0 = hide the search box, 1 = show on title bar, 2 = show on client
system.search.maxheight Read/write,
numeric 		menu max height
system.search.maxwidth Read/write,
numeric 		menu max width
