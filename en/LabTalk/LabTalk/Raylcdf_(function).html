3.5.3.1.28 Raylcdf

raylcdf-func

Description:

cumulative distribution function for Rayleigh

Syntax:

double raylcdf(double x, double b[, int iTail])

Parameters:

x (input, double)
The value of the x variate.
b (input, double)
The scale parameter (σ or scale) of the Rayleigh distribution (b > 0).
iTail (input, int)
Tail type, 0 = both, 1 = upper, 2 = lower(default)
