3.5.3.1.12 Expcdf

expcdf-func

Description:

cumulative distribution function for exponential

Syntax:

double expcdf(const double x, double lambda[, int iTail)

Parameters:

x (input, double)
The value of the x variate.
lambda (input, double)
The rate parameter (λ > 0) of the exponential distribution
iTail (input, int)
Tail type, 0 = both, 1 = upper, 2 = lower(default)
