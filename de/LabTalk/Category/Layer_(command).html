Kurze Einführung

Führt verschiedene Operationen auf vorhandene Layer durch. Der Layerbefehl bezieht sich auf den aktiven Layer, es sei denn, es ist anders festgelegt.

Viele dieser Funktionen können jetzt mit der X-Funktion laymanage bearbeitet werden.

Syntax:

layer [option] <width height xOffset yOffset>

Optionen:

Optionen für Diagramme

Option Beschreibung
no option Layerposition festlegen
-a X- und Y-Achsen des aktiven Layers neu skalieren, um alle in diesem Layer gezeichneten Daten zu zeigen
-a ma X- und Y-Achsen von allen verknüpften Layern zusammen neu skalieren, um alle Daten zu zeigen
-at X- und Y-Achsen des aktiven Layers neu skalieren, wobei die Einstellungen der Hilfsstriche ignoriert werden
-b 3DB Caching für die Grafikdarstellung festlegen
-cm l Eine gespeicherte Farbabbildung laden
-cm s Eine Farbabbildung speichern
-gru Namen der vorhandenen Diagrammobjekte in einem Layer eindeutig machen
-k Dialoge Details Zeichnung or Layer n öffnen
-n Einen nicht-verknüpften Layer zum aktiven Diagrammfenster hinzufügen
-n Both Einen verknüpften Layer zum aktiven Diagrammfenster hinzufügen, wobei eine obere X- und eine rechte Y-Achse angezeigt werden
-n X Einen verknüpften Layer zum aktiven Diagrammfenster hinzufügen, wobei eine obere X-Achse angezeigt wird
-n Y Einen verknüpften Layer zum aktiven Diagrammfenster hinzufügen, wobei eine rechte Y-Achse angezeigt wird
-p X- oder Y-Skalierung des aktiven Layers auf alle anderen Layer im aktiven Fenster anwenden
-u Die Einheiten ändern, in der Layergröße und -position gemessen werden
-x Die Dimensionen des Layerrahmens in Variablen erhalten

Optionen für spezielle Diagramme

Option Beschreibung
-3d Perspektive von 3D-Diagrammen steuern
-3d r Drehung von 3D-Diagrammen festlegen
-3d c GDI-basiertes 3D-Diagramm in OpenGL-Diagramm konvertieren
-cam Richtungen von 3D-OpenGL-Diagrammen steuern
-pgm Beliebiges Drehen und Abschneiden für kartesischen 2D-Layer aktivieren
-Y ? Wasserfalldiagramm im aktiven Diagrammfenster abfragen und den Variablen X und Y die Werte des X- und Y-Versatzes zuweisen
-Y ! X- und Y-Versätze im Wasserfalldiagramm im aktiven Diagrammfenster deaktivieren
-Y X- und Y-Versatz festlegen, um einen Wasserfalleffekt für alle im Layer gezeichneten Daten zu erzeugen
-z Winkel und Richtung Null für polares Diagramm festlegen

Optionen für Zeichnungen

Option Beschreibung
-b Spezielle Zeichenparameter
-c Im aktiven Layer gezeichnete Datensätze zählen
-cx X-Daten ändern
-cxy XY-Daten ändern
-cy Y-Daten ändern
-e Einen Datensatz aus dem aktiven Layer entfernen, aber den Platzhalter des Diagrammstils beibehalten
-g Datensätze im aktiven Layer gruppieren
-gu Gruppierung aller Datensätze im aktiven Layer aufheben
-hp Datenzeichnung(en) verbergen oder zeigen
-i Alle Platzhalter des Diagrammstils im aktiven Layer des Diagrammfensters löschen
-i dataset Einen Datenstz zum aktiven Layer hinzufügen
-i # Erneut in den Zeichnungstyp zeichnen, der mit # markiert ist
-ic Alle Datenzeichnungen aus dem festgelegten Layer in den aktiven Diagrammlayer kopieren
-ie Alle Platzhalter des Diagrammstils, die im aktiven Layer des Diagrammfensters nicht verwendet werden, löschen
-il Beschriftungen zu einer unbeschrifteten Datenzeichnung hinzufügen
-ip Einen Datensatz zum aktiven Layer hinzufügen, auch wenn der Datensatz im Layer vorhanden ist
-iu Alle Platzhalter des Diagrammstils löschen
-j Mehrere Datenzeichnungen extrahieren
-pd # Aktive Zeichnung in # Kopieb klonen (duplizieren)
-r Die Reihenfolge der Datenzeichnungen in aktiven Layer umkehren
-t nrow Die Arbeitsblattzeile festlegen, die den Achsentitel und den Legendentext für die Datenzeichnung liefert

Option Beschreibung
