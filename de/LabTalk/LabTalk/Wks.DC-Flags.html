Syntax

wks.DC.Flags

Access

Read/write
numeric

Description

Append data rows in imported file to active worksheet. As of Origin 2021, for Data Connector = Text/CSV only:

0 = (default)) Do not append
128 = append data by columns to current sheet on import
256 = append data by rows to current sheet on import

Examples

string next, fname, path$=system.path.program$ + "Samples\Batch Processing\"; 
findfiles fname:=fname$ ext:="*.csv";
wbook.dc.add("CSV");
wks.dc.flags=128;	// turn on append cols mode
int num = fname.GetNumTokens(CRLF);
loop(ii,1,num)
{
	next$ = fname.GetToken(ii, CRLF)$;
	wks.dc.source$=next$;
	wks.dc.import();
}
