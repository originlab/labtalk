System.Pagenav

System-Pagenav-obj

Read and alter Window Switcher settings


LabTalk Object Type:

Utility

The page object is a sub-object of the system object. The page object properties allow you to read and alter Window Switcher settings which are set in the YYSTEM.CNF file. These settings can also be accessed in the Options dialog box.


Properties:

Property Access Description
System.Pagenav.compact Read/write
numeric

Set the size of Window Switcher. system.pagenav.compact=0 to block all workspace
