Version

Origin 2024b

Syntax

wks.DC.cntrl

Access

Read/write
numeric

Description

Set/Get import option:

  • for JSON connector:
    1 = set Nested Arrays as Columns
  • for Minitab connector:
    0 = do not import outputs
    2 = import outputs to a tree structure

Examples

EX1: JSON connector 

wks.dc.cntrl = 0x00000001; //set nested arrays as columns when import JSON file

EX2: Minitab Connector 

newbook;
wbook.dc.add("Minitab");
wks.dc.source$="C:\MyFile\MSA alles_20250521.mpx";
wks.dc.sel$="Minitab";
wks.dc.cntrl = 2; // opt-in the "Import Outputs" cehckbox
wks.dc.import();
